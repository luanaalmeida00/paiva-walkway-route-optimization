#  Paiva Walkways Route Optimization

##  About the Project

This project was developed as part of the **Operations Research** course in the **BSc in Systems Engineering** at **ISEP – Instituto Superior de Engenharia do Porto**.

The project, **CLES – Caminhadas Lés-a-Lés**, focuses on optimizing walking routes through the **Paiva Walkways**.

The main challenge was to transform a real-world route planning problem into a mathematical optimization model capable of finding an optimal route while considering the available time and the points of interest visited along the way.

 **Final Grade: 18/20**

---

##  Objective

The objective of this project was to develop an optimization model to support the planning of a walking route through the Paiva Walkways.

Different points along the route were represented as nodes, including points of interest and relevant facilities.

The model considers two possible optimization perspectives:

###  Minimize Total Time

Find a route that minimizes the total walking and stopping time:

`Minimize: Travel Time + Time Spent at Visited Points`

###  Maximize Points of Interest

Find the route that maximizes the value of the points of interest visited while respecting the maximum available time:

`Maximize: Value of Visited Points`

After implementing and analysing both approaches, the second objective was selected as the most interesting for the project analysis.

---

##  Mathematical Model

The problem was modelled using **Mixed-Integer Linear Programming (MILP)**.

The model follows the structure of the **Shortest Path Problem**, extended with additional variables, constraints and parameters to better represent the characteristics of the walking route.

The implementation was developed using **Python** and **Google OR-Tools**.

---

##  Data and Nodes

The nodes along the Paiva Walkways were identified using geographical information and points of interest.

The following types of locations were considered:

* Viewpoints
* Toilets
* Waterfalls
* Picnic tables

The geographical coordinates of the points were used to calculate the distances between locations.

---

##  Distance Calculation

The distance matrix was calculated automatically using the **Haversine formula**.

This allows the distance between two locations to be calculated based on their GPS coordinates.

The resulting distance matrix is then used as input for the optimization model.

---

##  Model Parameters

The model allows different scenarios to be tested by changing its input parameters.

The analysis considers factors such as:

* Maximum available time
* Travel time between locations
* Time spent at points of interest
* Group size
* Fatigue
* Temperature
* Value and relevance of points of interest

These parameters make it possible to analyse how different conditions affect the optimal route.

---

##  Model Constraints

The optimization model includes constraints to ensure that the generated solution represents a valid route.

The constraints control aspects such as:

* Route continuity
* Valid movement between nodes
* Start and end conditions
* Maximum available time
* Selection of visited points
* Binary decision variables
* Consistency between the selected route and visited locations

---

##  Implementation

The project was implemented in **Python** using Jupyter Notebook.

The main stages of the implementation include:

1. Installation and import of the required libraries;
2. Definition of the Paiva Walkways data;
3. Automatic calculation of the distance matrix;
4. Definition of model parameters;
5. Pre-calculation of factors related to fatigue, group size and temperature;
6. Construction of the MILP model;
7. Definition of the objective function and constraints;
8. Solution of the optimization problem;
9. Analysis of the optimal route;
10. Functional testing with different group sizes;
11. Interactive visualization of the route.

---

##  Functional Testing

Different scenarios were tested to evaluate the behaviour of the optimization model.

In particular, the project analyses how changes in **group size** can affect:

* The selected route;
* Total walking time;
* Total time spent on the route;
* Feasibility of visiting different points of interest.

This allows the model to be evaluated under different conditions instead of relying on a single scenario.

---

##  Interactive Map

An interactive map was developed to visualize:

* All identified nodes;
* Points of interest;
* The optimal route generated by the model.

The visualization was implemented using **Folium** and **NetworkX**.

##  Key Takeaway

One of the main lessons from this project was understanding how a real-world problem can be translated into a mathematical model.

A seemingly simple question such as **"What is the best walking route?"** can involve several variables, constraints and objectives.

Operations Research provides the tools to structure these decisions, analyse different scenarios and identify optimal solutions.

> **A good optimization solution starts with a good representation of the problem.**
